# Scalper-Pro — نظام مضاربة سريعة

## الملفات
| ملف | وظيفته |
|---|---|
| `params.py` | كل الإعدادات (مؤشرات، خروج، مخاطر، عمولات) |
| `indicators.py` | EMA, RSI, ATR, ADX, Bollinger, VWAP, فلتر الإطار الأكبر |
| `strategy.py` | 3 استراتيجيات: Breakout / Pullback / MeanRev + فلتر تكلفة + فلتر ساعات |
| `engine.py` | التنفيذ وإدارة المخاطر (نفس الكود للباكتيست والورقي) |
| `backtest.py` | باكتيست + مقاييس + Monte Carlo |
| `optimize.py` | Walk-Forward (الرقم المعتد به هو OOS فقط) |
| `live.py` | تداول ورقي + تنبيهات على بيانات باينانس الحية (لا يرسل أوامر) |
| `tests.py` | اختبارات صحة (لا تسريب مستقبل، حسابات الربح والعمولة، حدود المخاطر) |

## التشغيل (Python 3.10+, pandas, numpy؛ matplotlib اختياري للرسم)
```
python tests.py
python main.py demo
python main.py fetch --symbol BTCUSDT --tf 15m --days 120 --out btc15m.csv
python main.py backtest --csv btc15m.csv --tf 15m
python main.py optimize --csv btc15m.csv --tf 15m
python main.py paper --symbol BTCUSDT --tf 15m
```

## ميزات المخاطر
- حجم الصفقة = 0.5% مخاطرة ÷ مسافة الستوب، مع سقف رافعة.
- نصف المخاطرة بعد خسارتين متتاليتين أو تراجع 10% عن القمة.
- إيقاف يومي عند -3%، حد صفقات يومي، تبريد بعد 4 خسائر، قاطع كلي عند -20% من القمة.
- ستوب متحرك + نقطة تعادل + خروج زمني. عند لمس الستوب والهدف في نفس الشمعة يُحسب الستوب أولاً.
- فلتر تكلفة: لا دخول إلا إذا الهدف >= 4 أضعاف تكلفة الصفقة (عمولات + انزلاق).

## قبل أي مال حقيقي
1. حمّل بيانات حقيقية، شغّل `backtest` ثم `optimize` وانظر أرقام OOS فقط.
2. شغّل `paper` أسابيع وقارنه بالباكتيست.
3. لا تبدأ بمال حقيقي إلا بمبلغ تتحمل خسارته كاملاً، وبمخاطرة أقل من الافتراضية.
